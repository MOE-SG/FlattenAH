# FlattenAH

Flatten Airhang HTML reports into a single-row CSV file that can be opened in Excel.

## Use

Open `FlattenAH.html` in a modern browser, then drop an `.htm` or `.html` Airhang report onto the page. Select **Download CSV** to save the flattened report. Use **Load new files** to clear the current result and process another report.

The parser runs locally in the browser. Report contents are not uploaded.
