Turn thousands of raw log rows into one summary row per test

Drop in one or more high-frequency time-series logs (temperature, pressure, etc. logged every few seconds) — this detects ramp / soak / cooldown phases, checks logging-interval consistency, and flags spikes worth a second look. Each file becomes one flattened row, ready to feed into the SPC Dashboard Generator. Nothing is uploaded anywhere.
